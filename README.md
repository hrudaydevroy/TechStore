## 📖 Project Overview

**TechStore** is a modern front-end e-commerce website created for selling and showcasing technology products.

The application provides a complete shopping experience from discovering products to managing a shopping cart and reaching the checkout page.

The project focuses on:

- 🎨 Modern and professional UI
- 📱 Fully responsive design
- ⚡ Fast development with Vite
- 🧩 Reusable React components
- 🔷 Type-safe development with TypeScript
- 🛒 Shopping cart management
- 💾 Local Storage persistence
- 🔎 Product filtering and sorting
- 🧭 Client-side navigation
- ✨ Smooth UI transitions and hover effects

---

# 🎯 Aim of the Project

The main aim of this project is to build a **real-world e-commerce front-end application** using modern web development technologies.

The project demonstrates how different React concepts can work together to create a complete shopping workflow.

### Main objectives

- Build a responsive e-commerce interface
- Create reusable React components
- Manage global cart state
- Implement product filtering
- Implement product sorting
- Create product detail pages
- Build a checkout interface
- Store cart data in Local Storage
- Use TypeScript for safer development
- Create a clean and scalable project structure
- Practice Git and GitHub version control

# 💾 Local Storage

TechStore uses browser **Local Storage** to persist shopping cart data.

This means the cart can remain available after:

- Refreshing the page
- Navigating to another page
- Closing and reopening the browser

### Data Flow

```text
User Action
     ↓
Cart Context
     ↓
Cart State Updated
     ↓
Local Storage
     ↓
Cart Data Persisted
```

# 🧠 State Management

TechStore uses **React Context API** to manage shopping cart state globally.

The main context is:

```text
src/context/CartContext.tsx
```

Typical cart operations include:

```text
addToCart()
removeFromCart()
updateQuantity()
clearCart()
```

The cart also calculates values such as:

```text
totalItems
subtotal
```

Components can access the cart state through the project's cart hook.

# 🔐 Security & Production Notes

This project is currently a **front-end e-commerce application**.

The checkout page is intended for UI demonstration.

For a real production e-commerce system, the project should be connected to:

- Secure backend APIs
- Database
- User authentication
- Order management
- Inventory management
- Secure payment gateway
- Server-side validation
- Secure payment processing

Sensitive payment information should never be stored directly in browser Local Storage.
